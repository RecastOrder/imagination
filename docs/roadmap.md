# 路线图：整体步骤、当前进度、需求池

> 这份文档回答三个问题：一共要做哪几步？现在在哪一步？新冒出来的需求放哪里？
> 每次讨论出新决定，就更新这里。

## 一、整体步骤

```
 ① 定义 ──▶ ② 界面原型 ──▶ ③ 后端地基 ──▶ ④ 知识库管线 ──▶ ⑤ 真实 AI 对话 ──▶ ⑥ 文件与存储 ──▶ ⑦ 项目模式与工具 ──▶ ⑧ 内测迭代 ──▶ ⑨ 上线运维
   （做什么）   （长什么样）   （数据存哪）     （资料怎么变成      （怎么回答、       （Office 预览、     （按项目协作、        （5 位建筑师）   （监控、备份、
                                             AI 能用的知识）      怎么引用）          网盘 / NAS）        GH 等小工具）                        安全）
            ▲ 我们在这里（原型大部分完成）
```

| 步骤 | 要定下来 / 做出来的东西 | 状态 |
|---|---|---|
| ① 定义 | 用户、核心任务、信息架构、权限模型 | ✓ 基本完成；**项目模式会改动信息架构，需要回到这一步补上** |
| ② 界面原型 | 所有页面、组件、状态、设计系统 | ✓ 大部分完成（演示数据） |
| ③ 后端地基 | 数据库、对象存储、账号与会话持久化、邮件服务、部署环境 | **进行中**：数据库（SQLite）✓、账号 / 会话 / 项目 / 权限 / 依据清单已持久化 ✓；个人标注已上服务器 ✓；待做：对象存储、笔记本上服务器、部署环境 |
| ④ 知识库管线 | 文档解析 → 切段 → 向量化 → 带权限标签的索引 → 检索 | 未开始（**最核心**） |
| ⑤ 真实 AI 对话 | 接入大模型、严谨 / 发散、引用校验、个人记忆 | 未开始（界面已就绪） |
| ⑥ 文件与存储 | 真实分块上传、**Office → PDF 转换服务**、NAS 代理、OneDrive 连接 | 未开始（浏览器端校验已完成） |
| ⑦ 项目模式与工具 | 项目空间、依据清单、知识沉淀；GH 生成器等工具接入 | 讨论中 |
| ⑧ 内测迭代 | 5 位建筑师试用 → 问题清单 → 修改 | 未开始 |
| ⑨ 上线运维 | 监控、备份、审计日志、安全检查 | 未开始 |

|---|---|---|---|

| 标注、框选、校准后测量尺寸 | 必须 | — | **✓ 已完成** |
| 标注共享：平时自己看，要给别人看就发起“问题” | 必须 | — | **✓ 已完成**（通知方式、指派待定） |

新需求的处理流程：**记进需求池 → 定优先级 → 判断属于哪一步 → 如果影响信息架构或数据结构，尽早处理**（数据结构越晚改，代价越大）。
