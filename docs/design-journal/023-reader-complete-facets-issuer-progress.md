# 023 PDF 阅读器配齐 · 按资料类型分类 · 出处写发布方 · 下载进度条

## 要解决的问题
owner 2026-09-26 深夜：
- 「阅读pdf时 小手 挪动位置 似乎不好用。 是不是可以把pdf的阅读逻辑在这里配置完整，似乎好多东西都不完整。」
- 「分类可以按照你的分类逻辑做」（spec 107）
- 「出版社就标注出版社，住建部就标注住建部，出处按照规范的出处逻辑标注。」
- 「在load 文件的时候，是否可以添加一个进度条，和一个大概的时间。」

## 方案

**PDF 阅读器**（对照 pdf.js 官方阅读器 / Chrome / Acrobat 配齐）
```
 − 95% + ↔ ⬚ 🔍 ⟳ │ ˄ [ 5 ] / 80 ˅ │ ☰目录 🔎查找 Ⅰ选文字 │ ✋ 📏 ⌖ │ 💬 ⊙
```
| 功能 | 怎么用 |
|---|---|
| 手形拖动 | 浏览工具（✋）时按住拖页面 —— 之前这个工具只是「不标注」，没实现拖动 |
| 适应宽度 ↔ / 适应整页 ⬚ | 每页各自缩放；整页＝一页的宽和高都放进窗口 |
| Ctrl/⌘ + 滚轮、触控板双指 | 以指针为中心缩放 |
| 框选放大 🔍 | 拖框，松手放大到框宽填满 |
| 旋转 ⟳ | 顺时针 90°；旋转后标注层暂不显示（标注坐标按未旋转的页记），要标注请转回 0° |
| 翻页 | 输入页码回车 · ˄ ˅ · PageUp/PageDown/Home/End · 记住上次读到的页 |
| 目录 ☰ | PDF 自带书签；没有就明说没有 |
| 查找 🔎（Ctrl F） | 高亮、按「有结果的页」逐页跳（回车＝下一页）；**扫描件只有部分页带文字时明说「只有 N 页能查」**，全文查找请用「文本」视图 |
| 选文字 Ⅰ | 打开后可以选中复制原件里的文字（扫描页没有文字） |

**按资料类型分类**：只选一种资料类型时才出现它自己的维度 —— 规范：规范类型（按效力层级排序）；图集：来源、专业与专题（不显示地区）；杂志：刊名。换类型时清掉上一类的专属条件。

**出处一行**：`出处：国标电子书库 [出版社电子书库] · 取回于 2026-08-31 · 原网址 （车道 ebook-books）` —— 先写谁发的、哪一档，车道名是内部标识放最后。

**下载进度条**：边收边算 —— 已收 / 总大小 · 百分比 · 速度 · 约剩多久；没有总大小时只报已收与速度，不假装知道还剩多久。

## 用到的设计知识
- **对标成熟产品的功能清单**（feature parity）：阅读器是用户已经有肌肉记忆的东西，快捷键与按钮位置照主流阅读器来，学习成本最低。
- **渐进披露（progressive disclosure）**：不相关的筛选维度不出现，选了类型才展开那一类的维度。
- **系统状态可见**（Nielsen 第 1 条）：进度条、「只有 N 页能查」、「没有自带目录」都是把系统此刻的状态说出来。

## 备选方案与取舍
| 方案 | 结论 |
|---|---|
| 换成 pdf.js 官方整套 PDFViewer 组件 | 不用：我们的标注/测量层挂在自己的页面结构上，换壳要重做标注；只借它的文字层（TextLayer）与样式 |
| 查找改用我们的识别正文 | 这一版不做：识别正文和原件页面位置对不上，高亮不了；先明说查不全，并指向「文本」视图 |
| 下载与打印按钮 | 这一版不做：原件不对外转发（R47），要不要给成员开放下载待 owner 定 |
