# 设计决策日志

每做一个 UI 模块，记录一篇。目的有两个：**沉淀为什么这样做**，以及**边做边学设计知识**。

文件命名：`NNN-模块名.md`，编号递增。

## 模板

```md
# NNN 模块名

## 要解决的问题
一两句话。

## 方案（配图）
布局草图 / 截图 / 流程图。

## 用到的设计知识
- **术语**：一句话解释。出处（Laws of UX / Refactoring UI / HIG / Material / WCAG）。

## 备选方案与取舍
| 方案 | 优点 | 缺点 | 结论 |

## 待你决定
- [ ] 问题？A / B（推荐 A，因为…）

## 改动位置
涉及的文件。
```
