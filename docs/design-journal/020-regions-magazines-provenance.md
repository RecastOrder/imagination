# 020 地区两层 · 杂志按刊名 · 点卡进原件 · 对外只放有出处的资料

## 要解决的问题
owner 2026-09-26 同一天说了四件事：
- 「地区里面要有 国家的区分，然后才是地区的区分。 shanghai 和上海 是同一个地址。」
- 「在地区后面的数字似乎被材料列表给遮挡了部分」
- 「我们的杂志也可以按照类别也录入进来吧。」「点击了资料的连接就该可以阅读原件。而不是简单的目录。」
- 「我们出现在cairn的信息要严谨……那么之前没有出处的资料不能被对外的页面看到。」（纲领 R154）

## 方案

```
筛选栏                                阅读页
┌─────────────────────┐              ┌──────────────────────────────────────────┐
│ 地区                 │              │ ← 资料库   [杂志] Arcade · 1986-spring  [文本|原版] │
│ ☑ 中国        73,438 │ ▸ 展开        │ 出处：抓取车道 usmodernist-mirror · 台账没记 · 原网址 │
│    ☐ 中国 · 上海市  725 │              │ ┌────────────── PDF.js 原件 ──────────────┐ │
│ ☐ 美国           …   │              │ │                                          │ │
│ 刊名                 │              │ └──────────────────────────────────────────┘ │
│ ☐ Architectural Record│              └──────────────────────────────────────────┘
└─────────────────────┘
```

- **地区两层**：每条资料的地区是「国家」或「国家 · 地区」，中国第二层是省级。规则只写在 hold 的 `regions.py` 一处（地标编号按 GB/T 2260 读省份、媒体地点中英文归一）。选「中国」包含全部下级。
- **计数不被遮挡**：筛选栏的 `fieldset` 默认最小宽度是内容宽度，会把数字挤到列表下面 ⇒ `min-w-0` + 数字 `shrink-0`。
- **杂志按刊名**：刊名全名取自上游每刊页面（带出处），分面里多一组「刊名」。
- **点卡直接进阅读页**，有原件时默认打开原件。
- **出处闸（R154）**：hold 建目录时，规范/图集只收抓取车道台账里按 sha256 对得上、记了网址的那一份；书库、书架、收件箱同编号的文件一律不收；媒体要原网址；杂志要镜像台账网址，并验文件头是不是真 PDF（181 期是网页冒充的）。本平台自己的资料卡没有取件记录 ⇒ 不进列表、按 id 也打不开。阅读页多一行「出处」。

## 用到的设计知识
- **分面导航（Faceted navigation）的层级分面**：父级计数包含子级，选父级＝选全部子级；子级默认折叠；选了下级的国家任何时候都自动展开（手动收起的尊重用户）（Nielsen Norman Group 对分面的建议）。
- **来源可追溯（Provenance）**：W3C PROV-O（2013）把「谁·何时·从哪取回」定成三件事；我们在页面上只显示读者核对得了的那三样。
- **诚实的系统状态**：台账没记的时刻写「台账没记」，不拿文件修改时间冒充。

## 备选方案与取舍
| 方案 | 结论 |
|---|---|
| 按编号去重、取正文最长的那份 | 不用：会从收件箱里挑出一份来源不明的文件代表这个编号 |
| 资料卡上的 `origin` 栏算出处 | 不用：那是我们自己写的来处描述，不是取件记录 |
| 只有站内编号（nrsis、ccsn）也算出处 | 此刻不算，等 owner 裁；不许拼网址 |
| 点卡先开预览面板 | 不用：owner 要「点了就读原件」 |

## 需要负责人做的判断
「只有站内编号、没有网址」的规范（自然资源部 nrsis 约 4.4 万份、工程建设标准化 ccsn 1,555 份）算不算有出处 —— 推荐：**先不算**，等这两条车道把网址补进台账再放出来（代价：这两类此刻在资料库里看不到）。
